## Игра "Змейка"

Краткое описание: Игрок управляет змейкой, которая движется по игровому полю. Цель — увеличивать длину змейки, «съедая» появляющиеся на экране яблоки.


## Требования

- Python 3.10+
- зависимости: см. `requirements.txt`

Необходимо активировать виртуальное окружение:
Команда для Windows:
python -m venv venv
source venv/Scripts/activate

Команда для Linux и macOS:
python3 -m venv venv
source venv/bin/activate

Установить зависимости из requirements.txt - выполнить команду: pip install -r requirements.txt
